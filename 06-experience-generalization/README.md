# 第 6 阶段：从真实经验到可引导的泛化

这一阶段以两篇论文回答两个相连的问题：**一个已有 VLA 如何靠真实执行变得更快、更稳？**以及**多个任务专家积累的经验如何回流到一个通用模型，并让人用语言、图像和质量要求引导它？**前者是 π*₀.₆ 的 Recap，后者是 π₀.₇ 的多模态上下文训练。[π*₀.₆ 原论文](https://arxiv.org/html/2511.14759v2) · [π₀.₇ 原论文](https://arxiv.org/html/2604.15483v2)
