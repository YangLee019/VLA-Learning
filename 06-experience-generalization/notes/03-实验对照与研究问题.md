# 第 3 讲：把“从经验学习”与“通用泛化”放到同一坐标系

> 对照依据：[π*₀.₆ 论文 v2 §VI–VII](https://arxiv.org/html/2511.14759v2)和[π₀.₇ 论文 v2 §IX–X](https://arxiv.org/html/2604.15483v2)。本讲可作为阶段复盘；详细算法见[第 1 讲](./01-Recap与pi-star-06.md)，模型实现见[第 2 讲](./02-pi07-架构与训练.md)。

## 1. 两条改进路径的因果地图

| 问题 | π*₀.₆ / Recap | π₀.₇ |
| --- | --- | --- |
| 首要目标 | 目标任务实机练习后提升可靠性与速度 | 一个通用 checkpoint 可被多种提示引导，吸收异质数据 |
| 主要新信息 | 自主尝试、成败、完成时间、可选人工接管 | 带速度/质量/错误元数据的多质量轨迹、子任务、图像目标、历史 |
| 如何区分好坏行为 | critic 估优势、二值化成正/负条件 | 训练轨迹标注成提示条件，部署请求较好模式 |
| 是否需目标任务采集/更新 | 论文主要结果是目标任务示范 + 实机迭代 | 熟悉高难任务对单一模型无单独后训练；新长任务可经语言指导再训练高层策略 |

它们有一个有意思的闭环：**专家实机 RL 产生较好和较差轨迹 → 通用模型带质量标签吸收 → 通用模型在新任务上经提示/指导运行 → 新轨迹又可能用于下一轮专家改进**。论文直接证明了前两段若干任务上的效果；最后一段是可研究的组合方向，不应写成已验证的完整自动闭环。[π₀.₇ §VI-A、X](https://arxiv.org/html/2604.15483v2)

## 2. 如何读实验，避免指标和任务分布混淆

**成功率**是符合任务评分规则的 episode 比例；**throughput** 是每小时成功完成次数，同时含成功率、完成速度、重置/计时口径。π*₀.₆ 的论文显示不同任务两种指标的变化可不一致：简单衣物任务已接近成功率天花板，仍可提高 throughput。读图 7–12 时先找纵轴，再看比较基线究竟是纯监督 π₀.₆、离线 RL 预训练 π*₀.₆，还是加目标任务 SFT 的 π*₀.₆。[π*₀.₆ §VI-C](https://arxiv.org/html/2511.14759v2)

π₀.₇ 的评估分成**已见任务的开箱表现**、**未见指令/组合**、**任务跨机器人迁移**、**真人口头指导后的新长任务**。这四种“泛化”难度不同。图 6 与专家比的是已见高难任务，而且 π₀.₇ 训练数据包含 π*₀.₆ 的部分执行轨迹；图 12 的跨本体不代表目标机器人在所有任务上都零训练；图 14–16 的新长任务有更具体的人类指导，后续自治版还训练高层策略。[π₀.₇ §IX-A–D](https://arxiv.org/html/2604.15483v2)

## 3. 三个理论辨析

**优势条件与条件行为克隆。** Recap 的训练外形是条件监督学习，但标签 $I_t$ 来自任务回报、值函数和优势，意图把条件 $I=1$ 对应到比数据参考策略更好的动作子分布。称它“RL”有依据；称它“端到端 PPO”则错误。π₀.₇ 的速度/质量标签也是条件，但通常基于 episode 元数据和人工评注，而非每个动作相对于值函数的优势。因此两者不能只用“都加了 prompt”概括。[π*₀.₆ §IV](https://arxiv.org/html/2511.14759v2) · [π₀.₇ §V-C](https://arxiv.org/html/2604.15483v2)

**动作条件与动作评分。** Recap 的 critic 主要在训练时给轨迹标优势；执行阶段直接从 $I=1$ 的 VLA 采样。π₀.₇ 的世界模型给图像目标，不给每个候选动作算奖励；VLA 直接条件生成 chunk。两篇论文都没有把主系统写成“枚举动作、预测未来、搜索最优序列”的 MPC。[两篇论文的算法 1](https://arxiv.org/html/2511.14759v2)

**“zero-shot” 的单位。** 需要问：零样本的是任务、场景、物体实例、语言表达、本体、控制模式，还是整个组合？如果训练见过叠衣数据但未见 UR5e 上叠衣，只能说**在该任务–本体配对上零样本**。若测试前收集人类口头分步指导，是低层无动作训练下的 coaching；若再训练高层策略，就不是整个系统零更新。[π₀.₇ §IX–X](https://arxiv.org/html/2604.15483v2)

## 4. 一张“复现设计”清单

若未来想在公开小规模平台研究同类问题，先定义下面六件事，再谈模型大小：

1. **明确动作接口。** 本体状态、关节/末端动作、频率、chunk 长度、实际执行长度、图像相机及时间同步必须一致；只是维度补零不够。
2. **明确数据切分单位。** 按任务、场景、本体、物体实例及轨迹来源分层，避免旧模型评测轨迹流入宣称“新任务”的测试集。
3. **固定评估口径。** 二值成功规则、超时、重置是否计入 throughput、人工中途接管是否计入成功，都需要事先写清。
4. **分离数据量与条件质量。** 无元数据、有元数据、只用优质数据、加入失败、等量多样性对照各做一次，才能定位增益。
5. **审计 critic。** 画成功/失败轨迹上的 $V_t$ 曲线，检查负剩余时间是否与真实进度相关，尤其关注不同任务长度归一化、人工纠错强制正标和阈值选取。
6. **评估子目标可达性。** 将真实未来图、生成图、无图三组在同一任务上比较；分离图像质量与动作策略质量，避免把“图好看”误认为“可执行”。

这里是研究设计建议，并非两篇论文完整公开的复现实验配方。要真正复现还需要数据、权重、机器人、标注和计算资源；本仓库仅保存论文和学习讲义。

## 5. 带解析的复盘题

**题 1：失败 episode 的每一步都是坏动作吗？** 不是。一次任务可能早期动作正确、末端失败；回报和 critic 会给全程信息，而 N 步优势比较局部变化。若把所有失败动作标负，会丢掉可用技能；若 critic 值估得不准，也会错误归因。Recap 的优势条件是对这个问题的近似解决。[π*₀.₆ §IV-A/B](https://arxiv.org/html/2511.14759v2)

**题 2：π₀.₇ 为什么不简单只保留 top 30% 演示？** 低质量和失败轨迹带来额外状态覆盖及行为多样性；质量条件帮助训练时解释它们、推理时选好模式。图 18 在衣物任务显示仅过滤最佳数据会损失可用数据量。但若标签不可靠或动作质量与元数据不相关，加入劣质数据并不一定有益。[π₀.₇ §IX-E](https://arxiv.org/html/2604.15483v2)

**题 3：π₀.₇ 已经用了世界模型，能否说它用“世界模型规划”成功？** 只能说子目标生成模型提供了图像目标，部分实验改善迁移/语言跟随。论文主路径没有对多个预测动作后果做在线搜索与选择。若要研究规划，可把子目标图生成、动作执行、反馈闭环扩展为候选目标采样与成功概率评估，但那是新方法。[π₀.₇ §V-B、VII](https://arxiv.org/html/2604.15483v2)

**题 4：如果 π₀.₇ 在 espresso 胜过专家，证明 RL 不再需要吗？** 不。通用模型部分训练数据来自 RL 专家；它的成绩可视为将专家技能蒸馏回通用底座。论文还提出后续用该通用底座在新任务上再做经验学习。二者更像不同阶段的互补机制。[π₀.₇ §VI-A、X](https://arxiv.org/html/2604.15483v2)

## 6. 接向世界模型的阅读问题

下一个主题可围绕三个判断展开：**模型预测了什么**（下一帧、目标图、状态/奖励还是动作后果）；**预测结果如何影响决策**（条件生成、候选筛选、搜索规划、想象训练）；**误差如何被抑制**（短时域、闭环重规划、可信度与真实数据校准）。π₀.₇ 的子目标图像是一个入口，但“可生成未来图”与“能长期准确预测接触动力学”之间仍有大距离。具体方法比较应在世界模型阶段从相应原论文重新核对。
