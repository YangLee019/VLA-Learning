## 这一章的阅读边界

2.0 的 60,000 小时由约 50,000 小时机器人轨迹和约 10,000 小时人类第一视角视频组成；人类视频的手部轨迹要经重建与坐标标准化，并非直接等同机器人关节标签。“20 个机器人配置”反映预训练覆盖，不等于每种本体都在论文中完成等量实机评测。双查询未来特征蒸馏是一种辅助预测训练目标，不能等同可调用的完整世界模拟器。[论文 §3–6](https://arxiv.org/html/2607.06403v1)
